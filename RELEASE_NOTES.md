# SmartNotch 0.2.0

- Check for updates from SmartNotch’s menu on Mac or the editor and notification area on Windows.
- Receive periodic update checks, with an option to turn them off.
- See an Update available button beside the floating panel controls when a newer version is detected.
- Download updates in the app and choose when to install and restart.
- Keep scripts, cards, notes, reading position, and settings between updates.
